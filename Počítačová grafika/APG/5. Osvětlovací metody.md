## 1. Radiometrie

**Hlavní myšlenka:** Abychom mohli fyzikálně správně simulovat světlo, potřebujeme přesně definovat, co měříme. Radiometrie je věda o měření elektromagnetického záření — definuje veličiny a vztahy mezi nimi.

### Veličiny (hierarchie)

|Veličina|Symbol|Jednotka|Co měří|
|---|---|---|---|
|Zářivý tok (Radiant flux)|Φ|W|Celkový výkon záření — jak rychle fotony proudí|
|Irradiance|E|W/m²|Hustota **dopadajícího** toku na plochu|
|Radiozita / Radiant exitance|B, M|W/m²|Hustota **emitovaného** toku z plochy|
|Zářivost (Radiant intensity)|I|W/sr|Tok na jednotku prostorového úhlu|
|Zář (Radiance)|L|W/(m²·sr)|Tok na jednotku plochy a prostorového úhlu — **nejdůležitější**|

### Klíčové vztahy

```
E = dΦ / dA                          (irradiance = tok / plocha)
I = dΦ / dω                          (zářivost = tok / prostorový úhel)
L = d²Φ / (dA · cosθ · dω)          (zář)

E(x) = ∫_Ω  L(x,ω) · cosθ  dω      (irradiance = integrál záře přes hemisféru)
```

### Proč je zář (L) nejdůležitější

- Odezva snímače kamery a oka je **přímo úměrná záři**
- **Invariantní podél paprsku ve vakuu** → ray tracing stopuje právě záři
- Všechny ostatní veličiny lze získat integrací záře

### Lambertův zákon (cosθ faktor)

Šikmě dopadající světlo osvítí větší plochu za stejný výkon → nižší hustota energie:

```
E_skutečné = E · cosθ
```

> [!note] 🧠 Matějův příprdek
> Kolmý dopad:       Šikmý dopad:
   ↓↓↓
 ───────   
 malá plocha           větší plocha
 vysoká intenzita 
>
>		   
 ↘ ↘ ↘
 ─────────────
 větší plocha
 nižší intenzita
### Bodový zdroj světla — irradiance ve vzdálenosti d

```
E = I / d²        (bodový zdroj, kolmý dopad)
E = Φ / (4π·d²)  (izotropní zdroj — energie rozptýlena po celé sféře)
```

**Příklad — Slunce:** Φ = 3,86·10²⁶ W, d = 1,5·10¹¹ m → E = 1365 W/m² (solární konstanta)

### Radiometrie vs. Fotometrie

||Radiometrie|Fotometrie|
|---|---|---|
|Rozsah|EM záření 0,01 μm – 1 mm|Viditelné světlo 380–780 nm|
|Váhování|bez|CIE funkce jasu V(λ)|
|Zář|W/(m²·sr)|cd/m² (nit)|

## 2. Odraz světla a BRDF

**Hlavní myšlenka:** Vzhled povrchu závisí na geometrii, světelných zdrojích a odrazivosti materiálu. BRDF je matematický popis toho, jak materiál odráží světlo z libovolného příchozího směru do libovolného odchozího směru.

### Typy odrazu

```
DIFUZNÍ (matný)              SPEKULÁRNÍ (lesklý)
světlo → celá hemisféra      světlo → úzký směr
příklad: křída, sádrová      příklad: zrcadlo, leštěný kov
```

Reálné materiály jsou mix obou krajností.

### Rodina rozptylových funkcí

|Zkratka|Popis|
|---|---|
|**BRDF**|Bidirectional Reflectance Distribution Function — odraz (světlo zůstává na stejné straně)|
|**BTDF**|Bidirectional Transmittance DF — lom/průchod na druhou stranu|
|**BSDF**|BRDF + BTDF dohromady|
|**SVBRDF**|Spatially Varying BRDF — BRDF se mění po povrchu|
|**BSSRDF**|Subsurface Scattering — světlo vstoupí, rozptýlí se uvnitř, vyjde **jinde** (kůže, vosk, mléko)|
|**BTF**|Bidirectional Texture Function — naměřená data pro každý texel|

**Klíčový rozdíl BRDF vs BSSRDF:** BRDF předpokládá vstup a výstup ve **stejném bodě**. BSSRDF relaxuje — vstup xi ≠ výstup xo.

### Definice BRDF

```
fr(ωi, ωo) = dLr(ωo) / dEi(ωi)        [1/sr]

dEi = Li(ωi) · cosθi · dωi
```

- **ωi** = příchozí směr světla, popsaný dvěma úhly `(θi, φi)`
- **ωo** = odchozí směr pohledu, popsaný dvěma úhly `(θo, φo)`; BRDF je tedy obecně 4D funkce dvojice směrů
- Výsledek je **poměr** odražené radiance k příchozí irradianci

### Vlastnosti správné BRDF

1. **Helmholtzova reciprocita:** `fr(ωi, ωo) = fr(ωo, ωi)`
2. **Zachování energie:** `∫_Ω fr(ωi, ωo) · cosθo · dωo ≤ 1` pro všechna ωi

### Kategorie BRDF modelů

|Kategorie|Příklady|Vlastnosti|
|---|---|---|
|**Empirické**|Phong, Blinn-Phong, Ward|Rychlé, intuitivní, fyzikálně nepřesné|
|**Fyzikálně založené (PBR)**|Cook-Torrance, Oren-Nayar, Disney|vycházejí z fyzikálních principů; korektnost závisí na konkrétní normalizaci a kombinaci členů|
|**Naměřená data**|gonioreflektometr → tabulky|Nejpřesnější, těžko editovatelné|

## 3. Phong a Blinn-Phong

**Hlavní myšlenka:** Empirické lokální osvětlovací modely. Nezachycují globální osvětlení, ale jsou rychlé a intuitivní. Phong rozkládá barvu na tři složky: ambientní, difuzní, spekulární.

### Phongův model [1973]

```
I = IA + ID + IS
```


![[phong.png]]


**Ambientní (IA)** — konstantní pro celou scénu, aproximace GI:

```
IA = CA · CD · kA        kA ∈ ⟨0,1⟩
```
- CA - color of ambient light
- CD - surface color
- kA - ambient reflection coefficient


**Difuzní (ID)** — Lambertův odraz, **nezávisí na pozici kamery**:

```
ID = CL · CD · kD · max(L·N, 0)        kD ∈ ⟨0,1⟩
```
- CL - light color
- CD - surface color
- kD - Diffuse reflection coefficient
![[diffuse.png]]

cosα = L·N: šikmý dopad → méně energie na jednotku plochy.

**Spekulární (IS)** — závisí na úhlu β mezi odraženým paprskem R a pohledem E:

```
IS = CL · CS · kS · max(E·R, 0)^h      kS ∈ ⟨0,1⟩, h ∈ ⟨1,∞⟩

R = 2(L·N)N - L       (odvození: L = L_par + L_perp, při odrazu L_par změní znaménko)
```
- CS - specular color

h = shininess: malé h → široký odlesk, velké h → ostrý odlesk.

![[specular.png]]

**Praktická heuristika:** `kD + kS ≤ 1`. Samotný původní Phongův model ale není automaticky energeticky korektní; k tomu je potřeba normalizovaný tvar BRDF.

### Blinn-Phong [1975]

Místo R a E používá **half-vector H**:

```
H = normalize(L + E)
IS = CL · CS · kS · max(H·N, 0)^h
```

**Proč 4× větší h:** úhel γ mezi H a N ≈ β/2 → cos(β/2)^h' = cos(β)^h → h' ≈ 4h.

**Výhody Blinn-Phong:**

- Rychlejší (nepočítá R)
- Pokud jsou směry ke světlu i k pozorovateli konstantní, je konstantní i H
- Plynulejší chování při grazing angles
- Byl součástí OpenGL/DirectX fixed-function pipeline

### Fyzikálně korektní Phong [Lafortune & Willems 1994]

Normalizovaný tvar zajišťující reciprocitu a zachování energie:

```
fr = ((h+2) / 2π) · cos^h β
```

## 4. Shading v rasterizaci

**Shading** určuje, jak získáme barvu všech bodů rasterizovaného polygonu. Není to totéž jako osvětlovací model:

- **Phongův osvětlovací model** je vzorec `IA + ID + IS`.
- **Phong shading** je způsob interpolace normál a vyhodnocení zvoleného osvětlovacího modelu pro každý fragment.

### Constant / flat shading

Jedna normála a jedna výsledná barva pro celý polygon. Je nejrychlejší, ale jednotlivé stěny jsou zřetelně viditelné.

### Gouraud shading

1. Ve vrcholech vyhodnoť osvětlovací model.
2. Výsledné barvy interpoluj přes polygon.

Je rychlý a vhodný hlavně pro difuzní povrchy. Úzký spekulární odlesk ležící uvnitř polygonu ale může úplně minout, protože nebyl zachycen v žádném vrcholu. Výsledek také může při rotaci objektu časově kolísat.

### Phong shading

1. Interpoluj vrcholové normály přes polygon.
2. Normálu po interpolaci znovu normalizuj.
3. Osvětlovací model vyhodnoť pro každý fragment.

Je dražší než Gouraud shading, ale věrněji zachytí lesklé odlesky.

### Vrcholové normály a ostré hrany

Vrcholová normála se obvykle získá normalizovaným součtem normál sousedních stěn, často váženým plochou nebo úhlem u vrcholu. Přes ostrou hranu se normály neprůměrují: vrchol se pro shading rozdělí, případně se použije mezní **crease angle**.

| Metoda        | Co se interpoluje | Kde se počítá osvětlení | Cena     |
| ------------- | ----------------- | ----------------------- | -------- |
| Flat          | nic               | 1× na polygon           | nejnižší |
| Gouraud       | barva             | ve vrcholech            | střední  |
| Phong shading | normála           | v každém fragmentu      | nejvyšší |

## 5. Cook-Torrance (mikroploškový model)

**Hlavní myšlenka:** Každý reálný povrch je na mikroúrovni drsný — složen z mikroplošek, každá perfektně zrcadlová. Výsledné chování = statistika přes všechny mikroplošky. Cook-Torrance je konkrétní instance obecného mikroploškového frameworku D·G·F.

### Obecný mikroploškový framework

```
fr(ωi, ωo) = D(H) · G(ωi, ωo) · F(H,ωi)
             ───────────────────────────
                  4 · cosθi · cosθo
```

Aby mikroploška přispěla do výsledku, musí platit vše najednou:

1. Je správně natočená → **D**
2. Světlo na ni dopadne (není zastíněna) → **G**
3. Odraz se dostane k pozorovateli (není blokován) → **G**
4. Kolik světla se odrazí → **F**

### D — Normal Distribution Function

Kolik mikroplošek má normálu rovnou half-vectoru H = normalize(L+E).

**Beckmannova distribuce:**

```
D = exp(-tan²θh / α²) / (π · α² · cos⁴θh)
```

**GGX (Trowbridge-Reitz)** [Walter et al. 2007] — modernější, delší spekulární ocas:

```
D = α² / (π · (cos²θh · (α²-1) + 1)²)
```

α = roughness: malé α → úzký peak → ostrý odlesk; velké α → široký peak → matný odlesk.

GGX je standard v moderních PBR enginech (Disney BRDF, Unreal, Unity).

### G — Shadowing-Masking

Korekční faktor G ∈ ⟨0,1⟩ pro dvě situace:

- **Shadowing:** jiná mikroploška blokuje dopadající světlo
- **Masking:** jiná mikroploška blokuje odražené světlo cestou k pozorovateli

Klíčový případ: při velmi šikmých směrech omezuje `G` příspěvek mikroplošek, které jsou zastíněné nebo zakryté sousední mikrogeometrií. Tento jev původní Phongův model nepopisuje.

### F — Fresnelův člen

Na každém rozhraní materiálů se část světla odrazí, část projde. Poměr závisí na úhlu dopadu.

**Schlickova aproximace [1994]:**

```
F(ωh, ωi) = F0 + (1 - F0) · (1 - max(ωh·ωi, 0))⁵
```

Ve Fresnelově členu jde o úhel dopadu na samotnou mikroplošku, tedy úhel mezi příchozím směrem a half-vector normálou `ωh`, nikoli obecně o úhel vůči makroskopické normále povrchu.

F0 = odrazivost při kolmém dopadu:

```
Plast:   F0 ≈ 0.04    Železo: F0 ≈ 0.56
Zlato:   F0 ≈ 0.83    Stříbro: F0 ≈ 0.97
```

**Grazing angle:** když se úhel mezi směrem a normálou odrážející mikroplošky blíží 90°, `F → 1` pro libovolný materiál (například mokrý asfalt vypadá ze strany lesklejší).

**Proč kovy mají barevný odlesk:** F0 je různé pro různé vlnové délky:

```
Zlato: F0(červená)≈1.0, F0(zelená)≈0.86, F0(modrá)≈0.31 → zlatý odlesk
Plast: F0 stejné pro všechny λ → bílý odlesk
```

### Disney PBR model [Burley 2012]

Cook-Torrance + GGX + Oren-Nayar + parametr **metalness**:

```
metalness=0: difuzní + bílý spekulární (F0=0.04)
metalness=1: jen spekulární, albedo = F0 (barevný odlesk kovu)
```

## 6. Reflektanční rovnice

**Hlavní myšlenka:** Z BRDF a příchozího světla spočítáme výslednou barvu bodu integrací přes celou hemisféru.

```
Lr(x, ωo) = ∫_Ω  fr(ωi, ωo) · Li(x, ωi) · cosθi  dωi
```

- **fr** — jak moc povrch odráží (BRDF)
- **Li** — kolik světla přichází z každého směru
- **cosθi** — Lambertův faktor šikmého dopadu (Určuje, jak moc světlo zeslábne podle úhlu dopadu)
- Integrace přes hemisféru Ω nad bodem x

**Problém:** Li(x, ωi) závisí na odrazu od jiných povrchů → rekurze → řeší renderovací rovnice.

---

## 7. Renderovací rovnice [Kajiya 1986]

**Hlavní myšlenka:** Reflektanční rovnice rozšířená o vlastní emisi povrchu. Rekurzivní — Lo jednoho bodu závisí na Lo jiných bodů. Různé renderovací algoritmy jsou různé aproximace tohoto integrálu.

```
Lo(x, ωo) = Le(x, ωo) + ∫_Ω  fr(ωi, ωo) · Li(x, ωi) · cosθi  dωi
```

- **Le** = vlastní emise (světelné zdroje → nenulové, ostatní → 0)
- **Li(x, ωi) = Lo(y, -ωi)** → rekurze (světlo přichází od jiných povrchů)

> [!note] 🧠 Matějův příprdek — reflektanční vs. renderovací rovnice
> Představ si jeden bod `x` na povrchu a kameru, která se na něj dívá směrem `ωo`.
>
> **Reflektanční rovnice:** „Kolik světla se v bodě `x` odrazí ke kameře?“  
> Ze všech směrů horní hemisféry posbírá příchozí světlo `Li`, materiál ho upraví pomocí `fr` a šikmý dopad zeslabí pomocí `cosθi`. Výsledkem je pouze **odražené světlo `Lr`**.
>
> **Renderovací rovnice:** „Kolik světla celkem opouští bod `x` směrem ke kameře?“  
> Vezme odražené světlo z reflektanční rovnice a přidá **vlastní vyzařování `Le`**:
>
> `Lo = Le + Lr`
>
> Obyčejná zeď má `Le = 0`, takže pouze odráží světlo. Svítící žárovka má `Le > 0`, takže navíc sama svítí.
>
> Příchozí `Li` většinou vzniklo jako odchozí `Lo` jiného bodu scény. Proto se světlo mezi povrchy předává pořád dál a renderovací rovnice je **rekurzivní**.

**Proč nejde řešit analyticky:** nekonečná rekurze přes všechny body scény.

### Aproximace renderovací rovnice různými algoritmy

|Algoritmus|Co aproximuje|
|---|---|
|Whitted ray tracing|přímé lokální osvětlení a stíny + rekurzivní ideální odraz/lom|
|Path tracing|celý integrál (Monte Carlo)|
|Radiozita|jen difuzní přenos|

## 8. Whitted Ray Tracing [1980]

**Hlavní myšlenka:** Sledujeme paprsky zpětně — od kamery do scény. V každém průsečíku vysíláme stínové paprsky ke světlům, odražený paprsek a lomený paprsek (rekurzivně).

### Typy paprsků

```
Kamera → primární paprsek → průsečík P
                              ├── stínový paprsek → ke každému světlu
                              ├── odražený paprsek RR → rekurze
                              └── lomený paprsek RT → rekurze
```

### Algoritmus

```
TraceRay(paprsek R, hloubka H):
  1. Najdi průsečík P s nejbližším objektem
  2. Pokud žádný → vrať barvu pozadí
  3. Pro každý světelný zdroj: vyšli stínový paprsek
  4. Vyhodnoť lokální osvětlení (Phong) od viditelných zdrojů
  5. Pokud H < max_hloubka:
       Ir = ks · TraceRay(odražený RR, H+1)
       It = kt · TraceRay(lomený RT, H+1)
  6. Vrať: Ia + Σ(Id + Is) + Ir + It
```

### Odražený paprsek

```
R = 2(L·N)N - L    nebo    ωo = ωi - 2(ωi·n)n
```

### Lomený paprsek — Snellův zákon

```
ηi · sinθi = ηo · sinθo

Indexy lomu: vzduch 1.000, voda 1.33, sklo 1.60, diamant 2.40
```

![[schnell.png]]

**Totální vnitřní odraz:** sin²θt > 1 → k lomu nedojde, vše se odrazí.

### Cena stínových paprsků

V jednoduchém Whittedově algoritmu se z každého průsečíku vysílá paprsek ke každému světelnému zdroji, takže mohou tvořit dominantní část průsečíkových testů. Komplexita je naivně `O(R·N)` pro `R` paprsků a `N` objektů; dobře vyvážená BVH nebo kd-strom ji pro typický dotaz výrazně snižuje, často přibližně k `O(log N)`.

### Co Whitted umí a neumí

```
✅ ostré stíny, zrcadlové odrazy, lom, průhlednost
❌ měkké stíny, difuzní color bleeding, kaustiky, nepřímé osvětlení
```

Řeší přímé lokální osvětlení a řetězce ideálních spekulárních odrazů/lomů, ale ne obecný difuzní nepřímý přenos světla.

## 9. Path Tracing

**Hlavní myšlenka:** Monte Carlo aproximace celé renderovací rovnice. Místo deterministických odražených paprsků (Whitted) vzorkujeme náhodný směr z BRDF v každém průsečíku. Zvládá vše — difuzní i spekulární, přímé i nepřímé osvětlení.

### Klíčový rozdíl od Whitteda

```
Whitted:      průsečík → 1 odražený + 1 lomený (deterministické, jen spekulární)
Path tracing: průsečík → 1 náhodný směr vzorkováním BRDF (stochastické, libovolné)
```

### Monte Carlo integrace

```
∫ f(x) dx ≈ (1/N) · Σ f(xᵢ) / p(xᵢ)

p(xᵢ) = pravděpodobnost výběru vzorku xᵢ
```

Více vzorků (paprsků na pixel) → přesnější výsledek, méně šumu.

### Algoritmus

```
PathTrace(paprsek, hloubka):
  1. Najdi průsečík x
  2. Pokud žádný → vrať barvu pozadí
  3. barva = Le(x) + přímé osvětlení(x)
  4. Vzorkuj BRDF → náhodný směr ω
  5. barva += fr · PathTrace(nový paprsek) · cosθ / p(ω)
  6. Vrať barvu
```

### Ruská ruleta — zastavení rekurze

```
q = pravděpodobnost pokračování (např. 0.9)
  r < q  → pokračuj, výsledek VYDEL q   (nestranný odhad)
  r ≥ q  → ukonči, vrať 0
```

Bez dělení q → systematické podhodnocení (scéna tmavší než má být).

### Importance Sampling

Vzorkuj preferenčně směry kde je BRDF nebo Li velké → stejná kvalita za méně vzorků.

### Průhlednost

Path tracing řeší průhlednost automaticky — vzorkování BSDF zahrnuje i transmittanci (lomené směry). Whitted to musí řešit explicitní větví.

### Co Path Tracing umí navíc

```
✅ difuzní color bleeding, měkké stíny, kaustiky a obecné nepřímé osvětlení
✅ v limitě mnoha vzorků aproximuje celou renderovací rovnici
❌ pomalé — stovky až tisíce vzorků na pixel
```

## 10. Radiozita

**Hlavní myšlenka:** Místo sledování paprsků řeší rovnováhu energie mezi plochami scény jako soustavu lineárních rovnic. Funguje pouze pro difuzní povrchy — výsledek nezávisí na poloze kamery → předpočítáš jednou, prohlížíš N-krát.

### Předpoklady

1. **Difuzní povrchy** — radiance stejná ve všech směrech
2. **Patches** — scéna rozdělena na plošky s konstantní radiozitou

### Radiozitní rovnice

```
Bi = Be,i + ρi · Σj  Fij · Bj

Bi    = celková radiozita patche i [W/m²]   ← neznámá
Be,i  = vlastní emise (světlo≠0, ostatní=0) ← známá
ρi    = difuzní odrazivost                  ← známá
Fij   = form faktor (konfigurační faktor)   ← nutno spočítat
```

Vede na soustavu **N rovnic s N neznámými**.

### Form faktor Fij

```
Fij = část energie vyzářené patchem i která dopadne na patch j
    = jak moc patch i "vidí" patch j (Nusseltova analogie)

Reciprocita: Ai · Fij = Aj · Fji
```

### Výpočet Fij — Hemicube

Místo hemisféry použij **polokrychli** (5 stěn):

1. Umísti hemicube nad střed patche i
2. Promítni ostatní patches na stěny (z-buffer řeší viditelnost)
3. Každá buňka má předpočítaný δ-faktor (váha dle polohy)
4. Fij = součet δ-faktorů buněk kde je vidět patch j

### Progresivní radiozita [Cohen et al. 1988]

Iterativní metoda — vystřeluje energii z **nejjasnějšího** patche jako první:

```
Inicializuj: Bi = Be,i,  ΔBi = Be,i

Dokud nekonverguje:
  i = patch s max nevystřelenou silou Ai·ΔBi
  Spočítej Fij (hemicube)
  Pro každý j:
    ΔRad = ρj · ΔBi · Fij · Ai/Aj
    Bj  += ΔRad
    ΔBj += ΔRad
  ΔBi = 0
  Zobraz průběžný výsledek
```

Výhoda: průběžná vizualizace — scéna se rozjasňuje od zdrojů.

### Srovnání metod globální iluminace

||Radiozita|Whitted RT|Path Tracing|
|---|---|---|---|
|Typ povrchu|jen difuzní|difuzní lokálně + ideální odraz/lom|libovolný|
|Pohledová závislost|NE (předpočítej 1×)|ANO|ANO|
|Měkké stíny|✅|❌|✅|
|Spekulární odrazy|❌|✅|✅|
|Color bleeding|✅|❌|✅|
|Rychlost prohlížení|rychlé|pomalé|pomalé|
|Použití|lightmapy, archviz|zrcadla/sklo, klasický ray tracing|offline rendering|

### Varianty radiozity

- **Hierarchická radiozita:** patches v hierarchii, přenos energie se aproximuje mezi vhodnými úrovněmi a omezuje počet interakcí
- **Stochastická radiozita (MC):** paprsky místo form faktorů, random walk
- **Instantní radiozita (VPLs):** virtuální bodová světla generovaná foton tracingem, bez explicitního meshingu
