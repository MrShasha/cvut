KD tree krokovač

Demo je pro 2D body. Hloubka 0 porovnává x, hloubka 1 porovnává y, pak zase x. Nahoře je prostorové dělení, dole stromová reprezentace.
červená = x split
modrá = y split
Žlutý bod = aktuální uzel / nalezený výsledek.
Zelený bod = navštívený uzel.
Červené průhledné oblasti = oříznuté podstromy.
Růžový bod = query bod, žlutý kruh = aktuální best u nearest-neighbor.
