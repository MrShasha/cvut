Skip list krokovač

Demo ukazuje search, insert, delete a update. Věž uzlu vzniká házením mince: počet hlav před prvním ocasem určí, do jak vysoké úrovně se uzel dostane.
L0 = obyčejný linked list
vyšší L = zkratky
Zelená cesta = search path.
Žlutý okraj = aktuální/fokusovaný uzel.
Růžový okraj = target klíč při hledání.
Update klíče = delete starého + insert nového.
