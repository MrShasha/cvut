DNS algoritmus — 3D rozložení pro C = A·B

Vrstva k: proc(i,j,k) = A[i][k]·B[k][j]
Stiskni ▶ nebo krok vpřed.

Fáze algoritmu

0. Init: proc(i,j,0) má A[i][0..q-1], proc(0,j,k) má B[k][j]
1. Broadcast A podél k: proc(i,k,0)→(i,k,*) — všechny vrstvy k dostanou A[i][k]
2. Broadcast B podél i: proc(0,j,k)→(*,j,k) — všechny řádky dostanou B[k][j]
3. Lokální násobení: proc(i,j,k) = A[i][k] · B[k][j]
4. Redukce podél k: C[i][j] = Σ_k A[i][k]·B[k][j] sečte do proc(i,j,0)

Odvození složitosti

3D mřížka:q×q×q
Procesory:p = q³
Broadcast A:(tₛ+tᵥ)·log q
Broadcast B:(tₛ+tᵥ)·log q
Redukce:(tₛ+tᵥ)·log q
T_P (n³ proc):Θ(log n)
Pro p = q³ < n³ (bloky n/q × n/q):
T_P:n²/p^{2/3} + ...
Isoefektivita:Θ(p^{3/2})
Max p:O(n³/log³n)
⬆ Klíčový rozdíl od Cannona: DNS může použít O(n³) procesorů, Cannon jen O(n²)!
