S pipelinem: všechny kroky se překrývají:
Krok k (broadcast):tₛ + tᵥ·n
Počet kroků:n = 6
Výpočet/krok:n/p eliminací
T_P celkem:O(n²/p + n)
Pro p=n:O(n) = O(√T_S)
Cost = p·T_P:O(n³) = Θ(T_S) ✓
→ Cenově optimální!
