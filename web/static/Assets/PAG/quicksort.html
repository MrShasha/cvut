Postup PRAM quicksortu

1. Broadcast pivotu (náhodný prvek)
2. Každý proc porovná svůj prvek s pivotem
3. Prefix scan → výpočet cílových pozic
4. Paralelní přeuspořádání (concurrent write)
5. Rekurze na obě části

Složitost PRAM

Proc. (CRCW PRAM):p = n
Prefix scan / fáze:Θ(log n)
Úrovní rekurze:Θ(log n) expected
T_P celkem:Θ(log² n)
Cost = n·T_P:Θ(n log² n)
T_S optimální:Θ(n log n)
→ Cost-optimal?Ne (log n násobek)
