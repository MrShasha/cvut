KOLIZE: NE
Havranův Cenový Model CD
$$C_{total} = N_V \cdot C_V + N_P \cdot C_P + N_U \cdot C_U$$
N_V (testy obálek): 0
N_P (testy primitiv): 0
N_U (update/refit uzlů): 0
Zkouškový detail (Refitting): Pro deformovatelné objekty (např. animované postavy) je kompletní re-build BVH stromu příliš drahý. Využívá se bottom-up Refit – listy se přizpůsobí novým pozicím vrcholů a rodičovské AABB se exaktně přepočítají jako sjednocení obálek svých dětí: $AABB(parent) = AABB(child_1) \cup AABB(child_2)$.
