Rovnoběžné přímky v P3

V afinní části se přímky neprotnou. V projektivním uzávěru sdílejí ideální bod svého směru.

Zadání L1: (1,0,0) -> (1,0,1)
L2: (1,1,0) -> (1,1,1)
d = (0,0,1)
L1 v rovině y = 0 L2 v rovině x - y = 0 společný ideální bod směru z společná rovina x = 1
Afinní pohled L1 a L2 jsou různé svislé přímky. Mají stejný směr, ale žádný konečný společný bod.
Projektivní průnik: P = [0, 0, 1, 0]^T
