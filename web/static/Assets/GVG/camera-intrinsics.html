Vnitrni parametry kamery

Matice K popisuje, jak se ortogonalni kamerove souradnice prepisou do obrazove baze beta.

Geometrief: vzdalenost C od roviny pi
u0: principal point
b1,b2: obrazove osy
gamma1,gamma2: ortogonalni kamera souradnice
kamera C a opticka osa obrazova rovina pi obrazova baze b1,b2 f a principal point u0
MaticeK = [k11 k12 k13; 0 k22 k23; 0 0 1]
k11,k22: meritko/focal
k12: skew mezi osami b1,b2
k13,k23: principal point
K je vnitrni cast projekce: zmeni souradnice paprsku, ne polohu kamery v prostoru.
