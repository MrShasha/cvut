Epipolarni geometrie

Bod X a centra kamer C1,C2 urcuji epipolarni rovinu. Jeji rezy s obrazovymi rovinami jsou epipolarni primky.

Rezy rovinsigma = plane(C1,C2,X)
l1 = sigma cap pi1
l2 = sigma cap pi2
Epipolye1 = line(C1,C2) cap pi1
e2 = line(C1,C2) cap pi2
x2^T F x1 = 0
Epipolarni primka l2 je mnozina moznych odpovidajicich bodu ve druhem obraze.
