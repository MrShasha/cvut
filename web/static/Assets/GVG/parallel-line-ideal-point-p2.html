Rovnoběžka přes ideální bod

Ideální bod neurčuje polohu, ale směr. Přímka přes konečný bod z a ideální bod y je proto rovnoběžná se všemi přímkami stejného směru.

Zadání x = [1,0,1]^T -> (1,0)
y = [1,2,0]^T -> směr (1,2)
z = [0,1,1]^T -> (0,1)
původní přímka přes x a y hledaná přímka přes z ideální bod y, směr (1,2) l∞: w = 0
Afinní pohled Bod y není konečný bod v rovině. V afinním obrázku se projeví jako směr se sklonem 2.
Výsledek: l = y x z = [-2,1,-1]^T -> -2u + v - 1 = 0
