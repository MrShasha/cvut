Průnik dvou podprostorů v R3

Dvě dvojice vektorů generují dvě roviny procházející počátkem. Jejich společná část je přímka.

Zadání
U = span((1,0,1), (0,1,1))
V = span((0,0,1), (1,1,0))
rovina U, tedy z = x + y rovina V, tedy y = x průnik L = span((1,1,2)) bázové vektory rovin
Myšlenka řešení
a(1,0,1) + b(0,1,1)
= c(0,0,1) + d(1,1,0)

a = d, b = d, c = 2d
Výsledek: průnik je jednorozměrný podprostor L = { d(1,1,2) | d ∈ R }
