Software architecture

Space-based architecture

Processing units a in-memory data grid omezují centrální bottleneck.
request: Traffic jde přes load balancer.
Princip

Aplikace běží ve více processing units. Data jsou distribuovaná a replikovaná v middleware/data grid vrstvě.

Kdy použít
  • extrémní zátěž
  • low-latency systémy
  • real-time analytics
  • high-performance transakce
Pozor na
  • velmi vysoká komplexita
  • consistency management
  • náročná infrastruktura
Quality attributes
high scalabilitylow latencydata grid
Flow
  1. 1Traffic jde přes load balancer.
  2. 2Request může obsloužit první processing unit.
  3. 3Jiný request může obsloužit další processing unit.
  4. 4Processing units se škálují horizontálně.
  5. 5Data jsou blízko výpočtu v gridu.
  6. 6Grid se replikuje nebo partitionuje.
  7. 7Každá partition drží část stavu.
  8. 8Trvalé úložiště může být až za gridem.
