Software architecture

Event-driven architecture

Komponenty publikují a odebírají události přes broker.
OrderCreated: Producer publikuje událost.
Princip

Producer nemusí znát všechny consumery. Systém reaguje na fakta, která už nastala.

Kdy použít
  • asynchronní workflow
  • více consumerů na jednu událost
  • stream processing
Pozor na
  • eventual consistency
  • složitější debugging
  • duplicity, ordering a idempotency

loose couplingscalable consumersasync flow

  4. 4Inventory reaguje nezávisle.
