Software architecture

Peer-to-peer architecture

Každý node může být klient i server.
share: Peer najde další nodes v síti.
Princip

Komunikace nemusí procházet centrálním serverem. Peers sdílí data nebo práci přímo mezi sebou.

Kdy použít
  • file sharing
  • blockchain
  • distributed storage
  • decentralized collaboration
Pozor na
  • složitější security
  • proměnlivá kvalita služby
  • těžší kontrola consistency
Quality attributes
decentralizedresilientshared resources
Flow
  1. 1Peer najde další nodes v síti.
  2. 2Peer A komunikuje přímo s Peer B.
  3. 3Peer B posílá data dál.
  4. 4Síť pokračuje i bez centrálního serveru.
  5. 5Peers sdílí resources mezi sebou.
  6. 6Discovery může být jen pomocná služba.
  7. 7Po discovery komunikace probíhá přímo.
