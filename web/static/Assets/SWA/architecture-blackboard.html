Blackboard architecture

Specializované knowledge sources sdílí částečné výsledky přes společnou tabuli.
activate: Control unit vybere další knowledge source.
Princip

Řešení vzniká iterativně. Control unit rozhoduje, který knowledge source má podle aktuálního stavu pracovat dál.

Kdy použít
  • AI reasoning
  • diagnostika
  • NLP
  • problémy bez pevné sekvence kroků
Pozor na
  • vysoká komplexita
  • nedeterministické chování
  • těžké testování control unit
Quality attributes
expert collaborationiterative solvingshared state
Flow
  1. 1Control unit vybere další knowledge source.
  2. 2Expert A přidá částečný závěr.
  3. 3Expert B čte a doplňuje blackboard.
  4. 4Expert C použije aktuální stav.
  5. 5Expert D validuje nebo zpřesní výsledek.
