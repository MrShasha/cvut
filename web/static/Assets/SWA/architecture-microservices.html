Software architecture

Microservices architecture

Služby jsou rozdělené kolem business capabilities a mohou se nasazovat nezávisle.
HTTPS: Klient volá gateway.
Princip

Každá služba má vlastní odpovědnost, API contract a často vlastní databázi. Výhodou je autonomie, cenou distribuovaná komplexita.

Kdy použít
  • velký systém s více týmy
  • nezávislé deploymenty
  • nezávislé škálování částí systému
Pozor na
  • network failures
  • data consistency
  • vyšší potřeba observability a DevOps
Quality attributes
team autonomyindependent deployfault isolation
Flow
  1. 1Klient volá gateway.
  2. 2Gateway směruje request na správnou službu.
  3. 3Order Service si vyžádá potřebná data přes API.
  4. 4Platba může být synchronní nebo event-driven.
  5. 5Každá služba vlastní svoji databázi.
  6. 6Order data nemění jiná služba přímo.
  7. 7Payment data jsou také izolovaná.
