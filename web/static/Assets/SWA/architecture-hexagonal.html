Software architecture

Hexagonal architecture

Business core je oddělený od technologií pomocí ports and adapters.
call: Driver adapter přijme vstup zvenku.
Princip

Core neví, jestli ho volá REST controller, CLI nebo test. Stejně tak neví, jestli persistence je PostgreSQL nebo externí API.

Kdy použít
  • důležitá business logika
  • potřeba testovat core bez DB/UI
  • časté změny externích technologií
Pozor na
  • více abstrakcí
  • overkill pro trivial CRUD
  • ports musí mít dobrý domain význam
Quality attributes
testable corelow framework couplingreplaceable adapters
Flow
  1. 1Driver adapter přijme vstup zvenku.
  2. 2Adapter volá input port.
  3. 3Core provede business pravidla bez znalosti frameworku.
  4. 4Core používá output port.
  5. 5Konkrétní adapter řeší DB nebo externí systém.
  6. 6Technologie lze měnit bez přepsání core.
