Microkernel architecture

Stabilní core a rozšíření přes plugins.
command: Uživatel spustí funkci přes core.
Princip

Core poskytuje základní runtime, lifecycle a plugin API. Funkce se přidávají jako plugins s jasným contractem.

Kdy použít
  • IDE, editor, browser
  • produktová platforma
  • systém s volitelnými rozšířeními
Pozor na
  • těžký návrh plugin API
  • verzování plugin contractu
  • testování kombinací pluginů

Flow
  1. 1Uživatel spustí funkci přes core.
  2. 2Core drží stabilní základ systému.
  3. 3Plugin API definuje povolené rozhraní.
  4. 4Plugin se připojí přes contract.
  5. 5Další pluginy lze přidat bez změny core.
