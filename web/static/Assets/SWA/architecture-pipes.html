Pipes and filters

Data procházejí sérií nezávislých filtrů.
pipe: Input vstoupí do prvního filtru.
Princip

Každý filtr dělá jednu transformaci. Pipe předává výstup jednoho filtru jako vstup dalšího.

Kdy použít
  • ETL
  • compiler pipeline
  • stream processing
  • image/audio processing
Pozor na
  • latence celé pipeline
  • error handling mezi kroky
  • stavové filtry komplikují návrh
Quality attributes
clear data flowreusable filterseasy unit tests
Flow
  1. 1Input vstoupí do prvního filtru.
  2. 2Parser převede vstup do struktury.
  3. 3Validator zkontroluje pravidla.
  4. 4Transform filtr změní tvar dat.
  5. 5Output je výsledek celé pipeline.
